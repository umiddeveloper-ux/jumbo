## 2. Реклама
**Содержит рекламу: Нет.** (В приложении нет рекламных SDK.)

## 3. Доступ к приложению (App access)
Весь функционал за входом (логином). Выберите «Некоторые функции ограничены» и дайте проверяющим готовую учётную запись.

Нужно, чтобы вы сами зарегистрировали тестовый аккаунт в приложении (например, логин `playreview`) и вписали логин и пароль в форму. Я такие аккаунты на боевом сервере не создаю.

Пояснение для проверяющих (вставить):
```
Sign in with the username and password above. Everything inside the app needs an account (learning is saved per account). Registration is free and takes three short steps; a phone number is optional.
```

## 4. Целевая аудитория и контент
| Вопрос | Ответ |
|---|---|
| Возрастные группы | 6–8, 9–12, 13–15, 16–17, 18+ (группу «5 и младше» я бы не выбирал: для регистрации и игр нужно уметь читать) |
| Привлекает ли детей | Да (приложение подходит детям, поэтому действует Families Policy) |
| Программа «Для всей семьи» (Designed for Families) | Можно участвовать: категория «Образование», нет рекламы, нет аналитики, есть политика и удаление аккаунта |

Требования Families Policy, которые приложение выполняет:
- Нет рекламы и рекламных SDK.
- Нет аналитики, отслеживающих SDK, идентификатора рекламы.
- Телефон необязателен; запрашивается только то, что нужно для обучения.
- Политика конфиденциальности доступна из приложения (Настройки → Политика конфиденциальности, регистрация).
- Удаление аккаунта в приложении и по ссылке.

## 7. Разрешения и их обоснование
| Разрешение | Зачем |
|---|---|
| INTERNET, ACCESS_NETWORK_STATE | Загрузка слов, прогресса, видео; проверка связи |
| CAMERA | Сканирование QR-кода, чтобы войти на сайте (необязательная функция) |
| FOREGROUND_SERVICE, FOREGROUND_SERVICE_MEDIA_PLAYBACK, WAKE_LOCK | Видео-уроки: служба воспроизведения |

**Декларация foreground service (тип «Воспроизведение медиа»)** — текст для консоли:
```
The app plays educational video lessons for each topic. Playback runs through the system media service (Media3 / ExoPlayer) so the video keeps running correctly when the screen is locked or the user briefly leaves the app. The service starts only when the user taps Play and stops when the video is paused or the lesson is closed.
```
Видео для проверяющих: можно записать экран эмулятора, где видео запускается на странице темы.
