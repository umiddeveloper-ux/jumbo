# Jumbo — материалы для Google Play

| Файл / папка | Куда в Play Console |
|---|---|
| `1-listing.md` | Карточка приложения: название, краткое и полное описание на ru / en / uz |
| `2-forms.md` | Ответы для форм: категория, реклама, доступ к приложению, целевая аудитория, рейтинг, безопасность данных, разрешения |
| `graphics/icon-512.png` | Значок приложения 512×512 |
| `graphics/feature-1024x500-ru.png` (en, uz) | Графика для карточки 1024×500 (по одной на язык) |
| `screenshots-ru/1…7*.png` | Скриншоты телефона 1120×2240 (2:1), русский интерфейс, новое оформление; светлая и тёмная тема по очереди (1, 3, 5, 7 — светлая; 2, 4, 6 — тёмная); по бокам оранжевые поля |
| `raw/` | Те же снимки в формате PNG с каналом прозрачности (можно не загружать) |

Скриншоты сняты на эмуляторе (1280×2856) с тестовым учеником и обрезаны/дополнены до 2:1: `design/app-shots/` — исходники. Для английского и узбекского интерфейса их можно переснять после смены языка в приложении.
Ссылки: политика https://jumbo.uz/privacy, удаление аккаунта https://jumbo.uz/delete-account, контакт kholmatov.javlon@gmail.com.
