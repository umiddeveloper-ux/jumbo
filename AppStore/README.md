# Jumbo — набор для App Store

| Что | Где |
|---|---|
| Тексты карточки: русский, английский, узбекский (название, подзаголовок, промо, ключевые слова, описание, «Что нового») | `1-listing.md` |
| Ответы на формы: возрастной рейтинг, конфиденциальность, шифрование, заметки для проверяющих, что делать вам | `2-forms.md` |
| Иконка 1024x1024, RGB, без прозрачности | `icon/AppIcon-1024.png` |
| Скриншоты, 7 штук для каждого размера, русские, RGB | `screenshots/` |

Размеры скриншотов:
| Слот в App Store Connect | Папка | Размер |
|---|---|---|
| iPhone 6.7" | `screenshots/iphone-6.7-1290x2796` | 1290x2796 |
| iPhone 6.5" | `screenshots/iphone-6.5-1284x2778` | 1284x2778 |
| iPhone 5.5" | `screenshots/iphone-5.5-1242x2208` | 1242x2208 |
| iPad Pro 12.9" | `screenshots/ipad-12.9-2048x2732` | 2048x2732 |

Порядок кадров (светлая и тёмная тема вперемешку): 01 главная, 02 змейка книги (тёмная), 03 тема со значком «Слова темы», 04 игра «Найди меня» (тёмная), 05 игра «Собери фразу», 06 награды и магазин (тёмная), 07 словарь.

Кадры сняты 13.11.2026 с эмулятора Pixel 9 Pro на версии приложения 38 (демо-ученик: серия 7 дней, 480 LP, 2 награды). Строка состояния и полоса жестов Android обрезаны, свободное место залито цветом края. Пересборка всех размеров (и для Google Play): `bash AppStore/make-screenshots.sh` (берёт кадры из `design/app-shots-v38/final`).

Для Google Play те же кадры лежат в `PlayStore/screenshots-ru` (1080x1920, 9:16), иконка 512 — `PlayStore/graphics/icon-512.png` (оранжевая, из той же иконки).

Внутри проекта для iOS-сборки нужны ещё `Jumbo/Resources/AppIcon/appicon.png` и `appiconfg.png` (MAUI делает из них все размеры иконок iOS); сейчас они голубые, старые.
